Variables, Operators & Conditions

Welcome to the revision module. Let's refresh our memory on the absolute basics.

Key Concepts

  • Variables: Dynamically typed in Python. No need to declare type.
  • Operators: Arithmetic (+, -, *, /, //, %, **), Logical (and, or, not).
  • Chained Conditions: Python uniquely allows mathematical chaining like 0 < x < 10.
⚡ Challenge: Guess the Code

Analyze the execution cycle of the following code snippet. What will be the final output printed to the console?

x = 15
y = 4
z = x // y + x % y

result = (z > 5) and (10 <= x < 20) or not (y == 4)

print(f"Z is {z}, Result is {result}")

Output: Z is 6, Result is True

Execution Cycle:

  • x // y is 15 // 4 = 3 (integer division).
  • x % y is 15 % 4 = 3 (remainder).
  • z = 3 + 3 = 6.
  • Condition 1: (z > 5) → (6 > 5) → True
  • Condition 2: (10 <= 15 < 20) → True
  • Condition 3: not (y == 4) → not True → False
  • Evaluation: True and True or False → True or False → True.

Control Flow (If/Elif/Else)

Control flow dictates how your program branches based on logical conditions.

Key Concepts

  • Python relies on indentation to define blocks of code, not curly braces {}.
  • An if block can be followed by zero or more elif blocks, and an optional else block at the end.
  • Only the first condition that evaluates to True will have its block executed.
⚡ Challenge: Guess the Output

What will be the output of this grading script if the score is 85?

score = 85

if score >= 90:
print("Grade A")
elif score >= 70:
    print("Grade C")
elif score >= 80:
    print("Grade B")
else
    print("Fail")

Surprise! This code actually won't run.

If you guessed "Grade C", you fell for the trap! Here is why it fails:

  1. Syntax Error: The print("Grade A") is not indented.
  2. Syntax Error: Missing colon : after the else keyword.

Even if you fix the syntax, there's a Logical Flaw: The order of elif statements is wrong. A score of 85 triggers score >= 70 and prints "Grade C", completely bypassing the score >= 80 check. Conditions should be ordered from most specific/highest to lowest!

Loops and Iterables

Loops allow us to execute a block of code multiple times.

Key Concepts

  • For loops: Used for iterating over a sequence (like a list, tuple, dictionary, set, or string).
  • While loops: Execute as long as a condition is true.
  • Iterables: Objects capable of returning their members one at a time.
🔢 Challenge: Iteration Math

Do the math! How many times will the string "Processing..." be printed?

counter = 10
iterations = 0

while counter > 0:
    print("Processing...")
    iterations += 1
    
    if counter % 2 == 0:
        counter = counter - 3
    else:
        counter = counter + 1

Output: The loop runs exactly 9 times.

The Math Trace:

  • Iter 1: c=10 (even) → c=7
  • Iter 2: c=7 (odd) → c=8
  • Iter 3: c=8 (even) → c=5
  • Iter 4: c=5 (odd) → c=6
  • Iter 5: c=6 (even) → c=3
  • Iter 6: c=3 (odd) → c=4
  • Iter 7: c=4 (even) → c=1
  • Iter 8: c=1 (odd) → c=2
  • Iter 9: c=2 (even) → c=-1
  • End: -1 > 0 is False. Loop terminates.
⚡ Challenge: The Break/Continue Trap

What will be the final value of total after this loop finishes?

total = 0
for i in range(1, 6):
    if i == 3:
        continue
    if i == 5:
        break
    total += i

Output: total will be 7.

The Execution Trace:

  • range(1, 6) generates numbers 1, 2, 3, 4, 5.
  • i = 1: total = 0 + 1 = 1
  • i = 2: total = 1 + 2 = 3
  • i = 3: continue triggers. The loop skips the rest of the code and goes to the next iteration.
  • i = 4: total = 3 + 4 = 7
  • i = 5: break triggers. The loop immediately terminates before adding to total.
  • Final total = 7.
🔢 Challenge: Nested Loop Math

How many times will "Inner" be printed?

outer_count = 3
inner_count = 4

for i in range(outer_count):
    for j in range(1, inner_count):
        print("Inner")

Output: "Inner" prints exactly 9 times.

The Math Trace:

  • The outer loop runs 3 times (for i = 0, 1, 2).
  • The inner loop runs for j in range(1, 4). Note that range(1, 4) generates numbers 1, 2, 3 (which is exactly 3 times).
  • Total iterations = Outer (3) × Inner (3) = 9.

Basic Data Structures & Mutability

Key Concepts

  • List: Ordered, mutable. [1, 2, 3]
  • Tuple: Ordered, immutable. (1, 2, 3)
  • Set: Unordered, unique items. {1, 2, 3}
  • Dictionary: Key-value pairs. {'a': 1}
  • Mutable: Can be changed in place (lists, dicts, sets).
  • Immutable: Cannot be changed after creation (strings, tuples, ints).
🐛 Challenge: Bug Bounty

Find the issues in this code snippet dealing with data structures.

# Task: Add an item to the data and create a backup

my_data = (1, 2, 3)
my_data[0] = 10

backup_data = my_data
backup_data.append(4)

print(my_data)

The Bugs:

  1. my_data = (1, 2, 3) creates a Tuple, which is immutable.
  2. my_data[0] = 10 will throw a TypeError: 'tuple' object does not support item assignment.
  3. backup_data.append(4) will fail because tuples do not have an append method.
  4. Conceptually (if my_data was a list): backup_data = my_data does not create a backup; it creates an alias pointing to the exact same list in memory. Modifying backup_data would modify my_data. You need my_data.copy() or list(my_data) to create an actual backup.

Functions & Common Methods

Functions encapsulate logic for reuse. Methods are functions that belong to objects.

🛠️ Challenge: Function Selection

Problem Statement: You are given a large string of comma-separated email addresses. You need to:

  1. Break the string into individual emails.
  2. Ensure there are no duplicates.
  3. Return them as a sorted list.

What specific Python built-in functions, data structures, and string methods would you use to achieve this efficiently?

The Solution Approach:

  • .split(',') : String method to break the comma-separated string into a list of individual email strings.
  • set() : Pass the list into a set to automatically remove all duplicate emails.
  • sorted() : Pass the set into the built-in sorted() function. This will sort the elements alphabetically and return a new list.

Code Example:

def process_emails(email_string):
    return sorted(set(email_string.split(',')))

File I/O

Interacting with the filesystem is a critical skill for data processing.

Key Concepts

  • Always use the with open() as f: context manager to ensure files are properly closed.
  • Modes: 'r' (read), 'w' (write - overwrites), 'a' (append).
⚡ Challenge: Guess the Output

Assuming log.txt currently contains the text "Session Start\n", what will be the exact contents of the file after running this script?

with open('log.txt', 'w') as file:
    file.write("Error: Invalid Input\n")

with open('log.txt', 'a') as file:
    file.write("Session End\n")

File Contents:

Error: Invalid Input
Session End

Why?

  • The first open(..., 'w') uses write mode. This completely overwrites the existing file, destroying "Session Start\n" and replacing it with "Error: Invalid Input\n".
  • The second open(..., 'a') uses append mode, which adds "Session End\n" to the end of the current contents.
