Functional Python

Functional programming paradigms treat computation as the evaluation of mathematical functions and avoid changing-state and mutable data. Python offers built-in support for these concepts.

Lambda Functions

Anonymous functions defined using the lambda keyword. They can have any number of arguments but only one expression.

# Syntax: lambda arguments: expression
add = lambda x, y: x + y
print(add(5, 3))

map()

Applies a given function to all items in an input iterable (like a list) and returns a map object (which can be converted back to a list).

nums = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, nums))
print(squared)

filter()

Constructs an iterator from elements of an iterable for which a given function returns True.

nums = [1, 2, 3, 4, 5, 6]
evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)

reduce()

Applies a rolling computation to sequential pairs of values in an iterable. It must be imported from functools.

from functools import reduce
nums = [1, 2, 3, 4]
product = reduce(lambda x, y: x * y, nums)
print(product)

apply()

While apply() was removed in Python 3 for general functions, it is a critical concept in Pandas (which we will cover in Tab 7) for applying a function along an axis of a DataFrame.

Iteration & Comprehensions

Python provides elegant ways to loop through data and create new collections.

zip()

Takes iterables, aggregates them in a tuple, and returns an iterator. It stops when the shortest iterable is exhausted.

names = ["Alice", "Bob", "Charlie"]
scores = [85, 92, 78]

for name, score in zip(names, scores):
    print(f"{name} scored {score}")

enumerate()

Adds a counter to an iterable and returns it in a form of enumerating object. Extremely useful when you need both the index and the value during a loop.

fruits = ["apple", "banana", "cherry"]
for index, fruit in enumerate(fruits, start=1):
    print(f"{index}: {fruit}")

List Comprehensions

A concise, readable way to create lists based on existing lists. They are generally faster than standard for-loops.

# Syntax: [expression for item in iterable if condition]
nums = [1, 2, 3, 4, 5]

squared = [x**2 for x in nums] 
evens = [x for x in nums if x % 2 == 0]

print("Squared:", squared)
print("Evens:", evens)

Error Handling (Exceptions)

Robust code anticipates and handles potential errors gracefully rather than crashing.

Try - Except - Finally

The try block lets you test a block of code for errors. The except block lets you handle the error. The finally block executes code regardless of the result.

def divide_numbers(x, y):
    try:
        # Code that might cause an exception
        result = x / y
        print(f"Result is {result}")
        
    except ZeroDivisionError:
        # Executes if a ZeroDivisionError occurs
        print("Error: Cannot divide by zero!")
        
    except TypeError:
        # Executes if a TypeError occurs
        print("Error: Inputs must be numbers.")
        
    finally:
        # Always executes, useful for closing files or connections
        print("Execution complete.")

# Test it out! Change x and y below.
divide_numbers(x, y)

NumPy Basics

NumPy (Numerical Python) is the foundational package for mathematical computing in Python, built around high-performance multi-dimensional array objects.

Array Creation

import numpy as np

# np.array(): Create from a standard Python list
arr1 = np.array([1, 2, 3])

# np.zeros(): Array filled with 0s (shape tuple required)
arr_zeros = np.zeros((2, 3))  # 2 rows, 3 columns

# np.ones(): Array filled with 1s
arr_ones = np.ones((2, 2))

# np.full(): Array filled with a specific value
arr_full = np.full((3, 3), 7) # 3x3 array of 7s

# np.eye(): Identity matrix (1s on diagonal, 0s elsewhere)
identity = np.eye(3)

print("np.zeros((2, 3)) output:\n", arr_zeros)
